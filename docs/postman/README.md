# Postman

## Importar

1. Abra o Postman e selecione **Import**.
2. Importe `rick-and-morty-api.postman_collection.json`.
3. Importe `rick-and-morty-api.postman_environment.json`.
4. Selecione o environment **Rick and Morty API - Local**.
5. Inicie a API e execute uma requisicao ou use **Run collection**.

O environment usa `http://localhost:3000`. As variaveis `characterId` e
`episodeId` podem ser alteradas sem editar as requisicoes.
